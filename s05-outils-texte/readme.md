# s05-outils-texte
Petite bibliothèque Python de fonctions utilitaires sur le texte et les listes.
## Ce que ça fait

`outils.py` contient quatre fonctions :

| Fonction | Rôle |
|---|---|
| `est_palindrome(texte)` | Dit si un texte se lit pareil dans les deux sens (majuscules et espaces ignorés) |
| `nettoyer(liste)` | Enlève les espaces autour, met en minuscules et supprime les éléments vides |
| `trier_personnes(personnes)` | Trie des `(nom, age)` par âge, puis par nom à âge égal |
| `afficher_tableau(personnes)` | Affiche les personnes dans un tableau aux colonnes alignées |
